This repository contains the source code for Homework 2: Graph Search Algorithms. It implements Breadth-First Search (BFS), Depth-First Search (DFS), and Iterative Deepening Depth-First Search (IDDFS) to measure and analyze their execution times on graphs of varying sizes.\

This program is written in Python and requires no external build system. To run the code, navigate to the directory in your terminal and execute:
python main.py
